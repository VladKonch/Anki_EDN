## Les Symboles !!
C'est un point qui rend plus difficile l'appropriation du paquet.
L'utilisation des symboles permet d'alléger le
contenu des cartes et de ne pas les polluer avec des mots de liaison inutiles. On peut alors se concentrer sur le contenu intéressant des cartes.
> Ne vous faites pas peur avec cette liste maintenant. 
> Travaillez avec cette page sous les yeux la première semaine ! On prend vite le coup.

- Symbole de liaison
  - ~ pour "environ"
  - \| pour "ou"
  - ∨ pour "et/ou"
  - & pour "et"
  - % pour "par rapport à"
  - α (un alpha) pour "est proportionnel à", "en fonction de", "dépend de" (même
    si ça devrait être ∝ normalement)
- Symbole autre
  - ↕ pour "arrêt"
  - ›› pour "début"
  - › pour "puis" ou "ensuite" ou "en énième intention"
  - ∀ pour "pour tout" ou "tous les"
  - ∃ pour "il existe" ou "il est possible"
  - ¬ pour "pas" ou "non" ou "dans le cas contraire"
  - Ø pour "non" ou "absence de"
  - ◊ pour "il est possible", "il y a parfois"
  - ☐ pour "il faut", "il doit", "il y a toujours"
- Abréviations
  - svr pour "sévère"
  - ctrl pour "contrôle"
  - R pour "rien", "aucun"
  - sup. pour "superficiel" ou "supérieur"
  - inf. pour "inférieur"
  - lat. pour "latéral"
  - méd. pour "médian" ou "médial"
  - sem. pour "semaine"
  - ATCD pour "antécédent"
  - FdR pour "facteur de risque"
  - vx pour "vaisseau·x"
  - n parmi k pour "combinaison"
- Autres
  - \+ répété <i>n</i> fois pour marquer l'importance (alternativement l'élément
    principal d'une liste ou l'intensité) de ce qui précède
  - \+ pour "positif"
  - \- pour "négatif"
  - S<i>n</i> pour "à la semaine <i>n</i>"
  - M<i>n</i> pour "au mois <i>n</i>" ou "à l'âge de <i>n</i> mois"
  - A<i>n</i> pour "à l'année <i>n</i>" ou "à l'âge de <i>n</i> ans"

>  Vous pouvez **l'imprimer, le mettre en fond d'écran...**
