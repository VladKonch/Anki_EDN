## 3 : Les Options de révisions 
Nous les optimisons de façon à ce que l'utilisation du paquet ne soit pas trop chronophage. 
- Sur la page d'acceuil, rendrez vous à droite du paquet dans `⚙️> options` 
- en haut, à droite de <span class="sauvegarde-anki-button">Sauvegarder</span>  cliquez sur `Ajouter un préréglage`.
### Les paramètres recommandés :
> Astuce : tous les modifications effectuées sont matérialisés par  signe 🔄

- Nombre maximum de nouvelles cartes par jour à 50 (c'est bien le maximum, il vaut mieux s'arrêter autour de 30-40 [^30-40]) ;
- Aucune limite sur le nombre de révisions quotidiennes ;
- Le FSRS (algorythme qui adapte l'espacement à l'utilisateur) gère les étapes (laissées vides) ;
- Ordre d'affichage optimisé pour maximiser l'attention et gagner du temps ;
- Seuil de pénibilité à 23 (les cartes échouées plus de 22 fois sont suspendues et retournent ainsi dans la reserve des cartes) ;
- Le taux de rétention du FSRS est calculé pour un apprentissage sur plusieurs années. Il est plutôt bas afin de ne rendre les révisions trop chronophages. Il conviendra de l'augmenter à partir de l'été D3 (et non pas pour les partiels, où vous privilégierez les QCM et les DP).
- Les "Cartes soeurs" n'apparaissent pas le même jour pour favoriser la mémoire à long terme;
- Le reste des règlages est identique à ceux par défaut. 

Pour en savoir plus sur les paramètres, [référez vous à cette vidéo](https://www.youtube.com/watch?v=uo-qQvOZDfg).
